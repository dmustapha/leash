## V2-M1 — VERY DEEP INTEGRATION IS THE FIRST-CLASS GATE (new, hard)
Every idea MUST be a genuine INTERLOCK: the product is IMPOSSIBLE if any one of its load-bearing sponsor primitives is removed, AND the COMPOSITION of primitives is itself the novel mechanism (not "product X that happens to use SDK Y").
- Name each load-bearing primitive and, for each, one sentence: "remove this and the product dies because ___." If removing it just makes it "a bit worse," it is DECORATIVE → the idea is killed.
- The winning shape stacks its (<=3 prize) sponsors so their primitives COMPOSE into an emergent capability none delivers alone. Prefer 3 deeply-interlocked sponsors over 1 deep + 2 shallow.
- Extra (non-prize) integrations are allowed ONLY if load-bearing; decorative "also uses" mentions are a kill signal, not a bonus.
- Depth test to state explicitly per idea: "one-sentence description WITH the interlock" vs "could a competitor rebuild this by swapping in a generic component?" If yes-rebuildable, not deep enough.

## V2-M2 — UNIQUE + IMPRESSIVE (raised novelty ceiling)
Target "no team at this event, reading the same prize page, independently builds this" (L12 cold pass). Modal shapes and single-sponsor-depth safe plays are DISFAVORED this round. The composition should make a judge say "I did not know you could do that." Impressive = the interlock produces a visible, on-chain-provable capability that looks like magic in 60 seconds.
