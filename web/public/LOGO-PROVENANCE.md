# LEASH logo provenance

- **Mark:** control-ring "mission control" emblem. A concentric ring holding a central agent node. The ring is the control layer; the node is the agent it holds.
- **Palette:** electric lime `#c6f24d` on near-black `#0a0a0b` (Signal Grid design system).

## Assets
- `favicon.svg`, `logo.svg`: clean inline vector of the control-ring mark (concentric ring + central node). 16px-legible, hand-authored. Used for the browser tab and crisp scaling.
- `logo.png`, `logo-16/32/64/256/512.png`, `apple-icon.png`, `og-image.png`: raster of the cinematic control-ring emblem. Used for OG / apple-touch / social.
  - **logo_provider:** pollinations
  - **subject:** control-ring emblem (mission-control ring around a central agent node)

## Retired
- `favicon.svg` / `logo.svg` previously drew an open amber collar-ring "clasp" mark on `#0b0b0d`. Superseded by the control-ring emblem in electric lime for the Signal Grid redesign (2026-09-13).
- `logo-v1/v2/v3.svg` are the legacy amber clasp studies (kept for reference only).
