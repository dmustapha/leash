01 / bind Beat one

Bind an agent that already exists.

LEASH does not create the agent. You point it at an on-chain-resolved ERC-8004 identity, then attach a 2-of-2 co-signed Hedera spending account: the agent holds one key, LEASH holds the other. Neither key spends alone.

bind → acme fleet
# identity is resolved, not issued agent = "payments-bot.agents.acme.eth" erc8004 = "0x8004…c1b7" // on-chain-resolved signer = "hedera:2of2" // agent + LEASH funding = "privy:independent-rail"

Privy is the independent second rail on the funding flow — it denies over-funding on its own, separate from the co-signer.

02 / declare Beat two

Declare the policy on the name itself.

The spend policy lives in the ENS resolver record. Rolling daily and weekly caps are a soft budget. The name is the single source of truth every rail reads from.

setText("leash.policy", { maxPerCall: 5 USDC, softBudget: { daily: 200, weekly: 900 }, allow: ["api.acme.dev"] })
