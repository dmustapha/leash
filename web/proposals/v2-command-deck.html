The control layer for AI agents

Mission control for the agents that spend your money.

One console to bind, govern, and cut off every agent in your fleet. When you revoke an agent, its next payment is blocked everywhere — instantly.

Open your console→ For judges: watch the 60-second live demo — no login
01

Connect an agent you already run

Your agent keeps its own identity and key and lives outside LEASH. You link it to a co-owned account — the agent and LEASH must both approve every payment.

02

Set plain-English spending rules

Up to $5 per payment. Up to $50 a day. Pay only api.acme.dev. The facilitator LEASH runs enforces the limits you set — no code required.

03

Cut it off with one click

Revoke an agent and it's cut off everywhere. Reactivate later if you choose. Funding is an independent rail, so you top up without touching the rules.

Bind an agent

Connect an agent you already run

The agent keeps its own identity and key. Binding sets up a co-owned account — the agent and LEASH must both approve every payment — and puts your rules under the facilitator LEASH runs.

How enforcement works: the facilitator LEASH runs enforces the limits you set on a co-owned account, where the agent and LEASH must both approve a payment. Identity is on-chain-resolved. Daily and weekly caps are a soft budget. Funding is an independent rail — top it up without changing the rules; over-funding is denied.
